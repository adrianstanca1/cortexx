# Agents

Core agents: Supervisor, Research Agent, Developer Agent, QA Agent.

Construction pack: Procurement Agent (supplier/RFQ analysis), Tender Scout (opportunity discovery and bid scoring), Document Analyst (contract/compliance extraction), Safety Agent (RAMS/incidents), Commercial Agent (costs/variations/invoices).

Agents declare capabilities, tools, model preference and permissions. The orchestrator assigns the best capability match and keeps sensitive actions behind approvals.
